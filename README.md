# B2B Sales Pipeline Analysis

## Project Overview

This project focuses on analyzing B2B sales pipeline data to understand sales performance, revenue generation, deal conversion, and sales agent performance.

The project combines data analysis using Python, SQL, Excel, and Power BI.

## Project Objectives

- Understand the overall sales pipeline.
- Calculate the sales win rate.
- Identify the highest revenue-generating products.
- Evaluate sales agent performance.
- Analyse won, lost, and open opportunities.
- Understand the time taken to close successful deals.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- SQL
- Microsoft Excel
- Power BI

## Dataset Description

The dataset contains 8,800 sales opportunities and the following columns:

- Opportunity ID
- Sales Agent
- Product
- Account
- Deal Stage
- Engagement Date
- Close Date
- Close Value
